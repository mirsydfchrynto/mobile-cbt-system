Tentang Aplikasi Ini

Okey Bimbel CBT Mobile adalah aplikasi Computer Based Test (CBT) resmi yang dirancang untuk mendukung kegiatan tryout, evaluasi harian, dan ujian berkala siswa bimbel.

Dibuat dengan fokus pada kemudahan navigasi bagi anak-anak usia sekolah serta ketahanan tinggi terhadap kondisi jaringan seluler yang fluktuatif di Indonesia.

Yang Baru di Versi 1.1.5 31 Agu 2026
  • Auto-Reconnection: Jawaban langsung terkirim otomatis saat internet pulih kembali.
  • Proteksi Jam HP: Durasi ujian tidak akan terpotong walau jam pada HP siswa berbeda.
  • Safe Image Rendering: Gambar soal beresolusi tinggi dimuat lancar tanpa kendala.

Keamanan Data & Privasi

Privasi siswa dan integritas data adalah prioritas utama sistem kami.

Terenkripsi di Perangkat: Data jawaban dienkripsi menggunakan Hive AES database lokal.
Tidak Ada Iklan / Pelacak Komersial: Aplikasi tidak mengambil kontak, galeri, maupun data analitik pihak ketiga.

Cara Memasang Aplikasi di HP Android

Ikuti 3 langkah mudah berikut untuk menginstal file APK dengan aman:

1

Unduh File APK

Tekan tombol "Download APK (80 MB)" di atas. Tunggu hingga proses pengunduhan di bilah notifikasi HP selesai 100%.

2

Izinkan Pemasangan

Buka file yang telah diunduh. Jika muncul pesan "File mungkin berbahaya", pilih "Tetap Download / Install Anyway" (Peringatan standar Android untuk file di luar Play Store).

3

Buka & Mulai Ujian

Buka aplikasi Okey Bimbel, masukkan nama lengkap siswa, dan arahkan kamera ke barcode ujian dari guru pengawas.
